# Прогнозирование оттока клиентов банка

В этом проекте решается задача классификации для банка: предсказать, уйдёт ли клиент в ближайшее время. На основе исторических данных о клиентах (кредитный рейтинг, возраст, баланс, активность и т.д.) строится модель машинного обучения, которая помогает банку вовремя предложить удерживающие мероприятия.

## Цель проекта
Разработать модель, которая по признакам клиента выдаёт вероятность оттока, и выбрать наилучший порог классификации, чтобы банк мог эффективно использовать ограниченные ресурсы колл-центра.

## Структура проекта
- **data/** – исходные данные (файл `churn.csv`)
- **notebooks/** – Jupyter Notebook с полным анализом и моделированием
- **README.md** – этот файл
- **requirements.txt** – используемые библиотеки

## Основные этапы работы
1. **Разведывательный анализ (EDA)**
   - Распределение целевого признака (`Exited`)
   - Связь возраста, баланса, страны с оттоком
   - Отсутствие пропусков, дисбаланс классов (~20% ушедших)

2. **Feature Engineering**
   - Созданы новые признаки: `BalanceSalaryRatio`, `TenureByAge`, `CreditScoreGivenAge`
   - One‑hot кодирование для `Geography` и `Gender`

3. **Моделирование**
   - Логистическая регрессия (базовая и с полиномиальными признаками 2-й степени)
   - Дерево решений (с ограничением глубины и без)
   - Случайный лес (500 деревьев, глубина 8, min_samples_leaf=10)

4. **Настройка порога классификации**
   - Подбор порога вероятности по F1-score (диапазон 0.1 – 0.95)
   - Улучшение итоговой метрики на 1-3%

5. **Интерпретация и вывод**
   - Анализ важности признаков (случайный лес)
   - Пример предсказания для нового клиента (Василия)

## Результаты моделирования
| Модель                                    | Test F1‑score |

| Логистическая регрессия (базовая)         | 0.44          |
| Логистическая регрессия + полиномы (deg=2)| 0.60          |
| Дерево решений (max_depth=8)              | 0.62          |
| **Случайный лес (500 деревьев, depth=8)** | **0.68**      |
| Случайный лес + оптимизация порога        | **0.71**      |
